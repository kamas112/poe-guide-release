# PoE 길잡이

카카오게임즈 **패스 오브 엑자일 1** 캠페인(1~10막)용 오버레이입니다. 게임 화면 위에 작은 칩과 지도 표시를 띄웁니다.

- **다음 출구 위치:** 게임 안 지도(Tab)에 다음 지역으로 가는 출구를 빨간 X로 표시합니다. 위치는 확률로 계산합니다.
- **막별 경로:** 지금 지역에서 다음에 갈 곳과 퀘스트 목표(보스, 퀘스트 아이템, 패시브 포인트)를 안내합니다.
- **빌드 도우미:** PoB(Path of Building) 주소를 불러오면 레벨별로 찍을 패시브와 넣을 젬 링크를 안내합니다.

## 설치

1. 이 저장소의 **Releases**에서 `PoEGuide-x.y.z.zip`을 받습니다.
2. 원하는 폴더에 압축을 풉니다. 설치 과정은 없습니다(포터블).
3. `PoEGuide\PoEGuide.exe`를 실행합니다.

### 처음 실행할 때 (한 번)

- **게임을 끈 상태**에서 실행하세요. 게임이 켜져 있으면 끌 때까지 기다립니다.
- 카카오 PoE 설치 폴더를 자동으로 찾습니다. 찾지 못하면 `Content.ggpk`가 있는 폴더를 직접 고르게 합니다.
- 내 PC의 게임 파일을 **읽기만** 해서 필요한 자료를 만들고 `data\` 폴더에 저장합니다. 1~2분 걸립니다.
- 패시브 트리 자료는 GGG의 공개 저장소(grindinggear/skilltree-export)에서 받습니다.
- 젬 구매처(퀘스트 뒤 상인이 파는 젬)는 게임 파일에 없어서 exile-leveling 공개 저장소에서 받습니다. 빌드를 불러올 때 받은 지 일주일이 지났으면 새로 받습니다.

### 게임이 패치된 뒤

- 게임 파일이 바뀐 것을 길잡이가 알아채면 **게임이 꺼져 있을 때** 자료를 새로 만듭니다. 창 없이 뒤에서 1~2분 걸리고, 다 되면 길잡이가 한 번 다시 켜집니다.
- 게임이 켜져 있는 동안에는 게임 파일을 읽지 않습니다. 패치 직후 첫 판은 이전 자료로 돌고, 게임을 끈 뒤에 새 자료로 바뀝니다.
- 새로 만들기에 실패하면 이전 자료로 계속 동작합니다.
- 0.1.3 이하에서 올라오면 자료를 한 번 새로 만들고 길잡이가 다시 켜집니다.

## 사용법

- 게임 안에서 지도(Tab)를 켜면 다음 출구에 X가 그려집니다.
- 칩을 **오른쪽 클릭**하면 메뉴가 열립니다.
  - 빌드 불러오기: PoB 주소나 코드를 복사한 뒤 누릅니다.
  - 빌드 선택, 지도 보정, 지도 표시 켜기/끄기, 종료
- 칩은 드래그해서 옮길 수 있습니다.

### 빌드 단계가 바뀌는 때

PoB의 패시브 트리와 젬 세트 이름을 보고 단계가 언제 바뀌는지 정합니다. 불러온 직후 칩에 결과가 잠깐 나옵니다. 예: `젬 단계: Lv1 · Lv12 · Lv18 · Lv28 · Lv61 · Lv71 · 노란 맵 · 빨간 맵`

| 이름 예 | 바뀌는 때 |
|---|---|
| `Lv 12`, `12-17`, `61 Crit Swap`, `Level 80`, `70렙` | 그 레벨 |
| `Act 5`, `5막` | 그 막에 들어갈 때 |
| `Maps`, `Early Mapping`, `Atlas` | 첫 맵 |
| `Midgame`, `Yellow Maps` | 노란 맵(6등급 이상) |
| `Endgame`, `Red Maps`, `Late Atlas`, `Pinnacle` | 빨간 맵(11등급 이상) |
| `T16` | 그 등급의 맵 |
| 때가 없는 이름(`Campaign Progression` 등) | 패시브 수로 추정한 레벨 |

- 같은 때를 가리키는 단계가 둘이면(`61 Crit Swap`, `61-Early Maps`) 뒤 단계는 앞 단계와 이 단계 트리의 중간만큼 패시브가 모일 때 바뀝니다(위 예에서 71레벨).
- 엔드게임 변형(`Day 2` 등)은 저절로 바뀌지 않습니다(`수동`). 메뉴의 **젬 다음 단계로**를 누르세요.
- 아직 구할 수 없는 젬(뒤 막의 보상이나 상인 것)은 젬 이름 옆에 회색으로 `6막`처럼 표시합니다.

## 업데이트

새 버전은 **자동으로** 받습니다. 길잡이를 켤 때와 켜 둔 동안 3시간마다 확인하고, 새 버전이 있으면 켠 직후에는 바로, 게임 중이면 게임 창이 앞에 없을 때 받아서 바꾼 뒤 다시 켜집니다. 프로그램 파일만 바뀌고 `data\`(게임 자료)와 `user\`(설정, 빌드, 기록)는 그대로입니다. 받기에 실패하면 칩에 표시되고, 메뉴의 **업데이트**로 직접 받을 수 있습니다.

0.1.1 이하를 쓰고 있다면 이번 한 번은 메뉴의 **업데이트**를 눌러 받아야 합니다. 그다음부터 자동입니다.

## 하는 것 / 하지 않는 것

| 하는 것 | 하지 않는 것 |
|---|---|
| 게임 화면 캡처(지도 영역, 창 판독) | 게임 메모리 읽기·쓰기, 게임 프로세스 접근 |
| 게임 로그 `logs\KakaoClient.txt` 읽기 | 키보드·마우스 입력 자동화, 전역 단축키 |
| 게임 데이터 파일 읽기 전용(처음 실행 때) | 네트워크 감시, 게임 파일이나 실행 파일 수정 |

비공식 팬 도구이며 Grinding Gear Games, 카카오게임즈와 관련이 없습니다. **사용에 따른 책임은 사용자 본인에게 있습니다.**

## 요구 사항

- Windows 10/11 64비트
- 카카오 패스 오브 엑자일 1 (스팀판과 해외판은 지원하지 않습니다)
- 1920×1080 화면을 기준으로 만들었습니다. 다른 해상도는 가로 비율로 맞추지만 확인하지 않았습니다.

## 폴더

- `PoEGuide.exe`, `_internal\`: 프로그램
- `data\`: 처음 실행할 때 내 게임에서 만든 자료 (배포 파일에는 들어 있지 않습니다)
- `user\`: 설정, 불러온 빌드. 메뉴에서 자료 기록을 켜면 지도 화면과 아이콘 위치도 여기에 저장합니다(기본은 꺼짐, 이 PC 밖으로 보내지 않음)
